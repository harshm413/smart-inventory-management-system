# Smart Inventory Management System

Automated inventory analytics, sales velocity tracking, and low-stock reorder management built with **Python, PostgreSQL, Pandas, and SQL Analytics**.

## Tech Stack
- **Backend & ETL:** Python, Pandas, psycopg2
- **Database & Analytics:** PostgreSQL, SQL KPI & Risk Views
- **Dashboard & Testing:** Streamlit, Pytest

## Quick Start
1. `pip install -r requirements.txt`
2. Configure `.env` from `.env.example`
3. `python src/run_pipeline.py`
4. `streamlit run app.py`
